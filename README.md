# Smart Carbon Matrix System

An intelligent matrix tracking system managing 200 carbon mold units. Powered by WS2812B RGB LEDs for active Pick-to-Light guidance and automated solenoid locks for secure, controlled access. Streamlines smart industrial inventory tracking, eliminates tool misplacement, and logs status changes in real time for error-free production storage.
